# BlackWolf Homebrew Tap

Homebrew casks for apps by BlackWolf.

```bash
brew install --cask rsng-phoenix/tap/game-audio-splitter
```

| Cask | App |
|---|---|
| `game-audio-splitter` | [Game Audio Splitter](https://github.com/Rsng-Phoenix/game-audio-splitter): play one app's sound on extra output devices |

Update with `brew upgrade --cask game-audio-splitter`. Remove with `brew uninstall --cask game-audio-splitter`
(add `--zap` to also remove settings).
